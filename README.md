# ai-for-the-arts-b
This project uses generative artificial intelligence to develop an image-recreation and story narrative from the object MS Euing 26,  available at the University of Glasgow Special Collections Page.

The main file/notebook here is defined as "lettering_project.ipynb".

This notebook encompasses an introduction/context section, detailing the context of the object used (MS Euing 26) as well as the objectives of the project. The methodology section encompasses my plan for the project, as well explanations of the tools used - Microsoft Copilot and Chat-GPT 4. The output results section showcases the results and working of the project, depicting textual analysis and image re-creations of initals and drawings inside of intials within the object MS Euing 26. Finally, the discussion and conclusion section evaluates the project with reference to the intended objectives.

There are 10 addiontional image files (8 png, 2 jpg) within this codespace which are displayed in the "lettering_project.ipynb" notebook for the purposes of augmenting all section in the project. Two of these are from external sources which are refernced appropriately in the notebook. The other eight are derived from my output results in Microsoft Copilot and Chat-GPT.
